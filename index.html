Vue.js component library · @mediusware/shaper-ui

A simple, opinionated UI library for Vue.js

Shaper UI gives Vue apps a ready set of components, from buttons and modals to data tables, steppers and date pickers, installed from npm.

$npm install @mediusware/shaper-ui

Get started

Install
npm install @mediusware/shaper-ui
Usage
<template>
  <Button @click="showModal = true">Click Me</Button>
  <Modal v-if="showModal" @close="showModal = false">
    Modal Content
  </Modal>
</template>

<script setup>
import { ref } from "vue";
import { Button, Modal } from "@mediusware/shaper-ui";
const showModal = ref(false);
</script>
